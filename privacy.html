NAGESEN プライバシーポリシー

更新日: 2026年10月21日 / 運営: poirotec

取得する情報と目的

利用者がGoogle認証で許可したチャンネル情報、配信・ライブチャットの識別子、収益イベントの識別子・表示名・金額・通貨・日時・種類、およびYouTube Analyticsの推定収益を読み取ります。取得情報は利用者自身の収益台帳、重複計上の防止、目標表示、Studio照合に使います。Googleのアクセストークンとリフレッシュトークンは、この読み取りアクセスを継続するために保存します。Googleのパスワードは取得しません。

保存とアクセス

アプリの情報と認証トークンは、運営者が管理する専用VPSへ保存します。管理画面はSSH接続と管理認証を使用します。表示用の読み取りリンクを持つ人は表示情報を閲覧できるため、リンクを公開しない運用です。公開用GitHub Pagesへトークン、台帳、収益レポートを保存・公開しません。

第三者への提供

Google APIとの通信と、VPS・表示クライアントでのアプリ運用のために情報を処理します。取得したGoogleユーザーデータを販売したり、広告目的で提供したり、汎用AI・機械学習モデルの学習へ使ったりしません。

この説明サイトはGitHub Pages上にあり、アクセス時のIPアドレス等はGitHubのサービス運用のために処理されます。詳しくはGitHubのプライバシー声明を参照してください。この説明サイトに独自のアクセス解析や広告は設置していません。

保持・削除・連携解除

台帳は利用者が履歴の削除・リセットを行うまで保持します。重複計上防止用の識別子は履歴削除後も保持します。DBバックアップは直近14コピーを保持するため、削除した記録が古いバックアップに残る場合があります。完全削除が必要な場合は運営者が台帳、識別子、バックアップおよび認証トークンを削除します。

Googleアカウントのサードパーティとの接続からアクセス権を取り消せます。アプリの連携解除操作でも保存トークンを削除します。アクセス権の取消しだけでは保存済み台帳は削除されません。データの削除・問い合わせは開発者の連絡先を利用してください。秘密情報や認証トークンを公開の問い合わせ欄へ書かないでください。

NAGESENによるGoogle APIから受け取った情報の使用および他のアプリへの転送は、Limited Use要件を含むGoogle API Services User Data Policyに従います。
